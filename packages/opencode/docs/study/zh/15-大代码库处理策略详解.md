## 问题背景

当处理大型代码库时，OpenCode 会面临以下限制：

### 1. Token 限制

不同模型的上下文限制：
```
Claude 3.5 Sonnet:  200,000 tokens
GPT-4o:            128,000 tokens
Claude 3 Haiku:     200,000 tokens
```

### 2. 实际可用 Token

实际可用 Token = 模型上下文限制 - 输出 Token 预留
```typescript
// src/session/compaction.ts:30-38
const context = input.model.limit.context        // 总上下文
const output = Math.min(input.model.limit.output, SessionPrompt.OUTPUT_TOKEN_MAX)
const usable = input.model.limit.input || context - output  // 实际可用
```

### 3. 触发场景

| 操作 | 消耗 Token 量 | 风险 |
|------|--------------|------|
| 读取一个大文件 (1000行) | ~10,000 tokens | 高 |
| 搜索整个项目 | 变化大 | 中 |
| 长对话历史 | 累积增长 | 高 |
| 多个工具调用 | 累积增长 | 中 |

### 触发条件

### 源代码详解

```typescript
// src/tool/truncation.ts:50-105
export async function output(
  text: string,
  options: Options = {},
  agent?: Agent.Info
): Promise<Result> {
  const maxLines = options.maxLines ?? MAX_LINES      // 默认 2000 行
  const maxBytes = options.maxBytes ?? MAX_BYTES      // 默认 50KB
  const direction = options.direction ?? "head"        // 默认从头开始

  const lines = text.split("\n")
  const totalBytes = Buffer.byteLength(text, "utf-8")

  // 步骤 1: 检查是否需要截断
  if (lines.length <= maxLines && totalBytes <= maxBytes) {
    return { content: text, truncated: false }
  }

  // 步骤 2: 计算保留内容
  const out: string[] = []
  let bytes = 0

  if (direction === "head") {
    // 从头开始，逐行添加
    for (let i = 0; i < lines.length && i < maxLines; i++) {
      const size = Buffer.byteLength(lines[i], "utf-8") + (i > 0 ? 1 : 0)
      if (bytes + size > maxBytes) break  // 字节限制
      out.push(lines[i])
      bytes += size
    }
  } else {
    // 从尾开始，逐行添加
    for (let i = lines.length - 1; i >= 0 && out.length < maxLines; i--) {
      const size = Buffer.byteLength(lines[i], "utf-8") + (out.length > 0 ? 1 : 0)
      if (bytes + size > maxBytes) break
      out.unshift(lines[i])
      bytes += size
    }
  }

  // 步骤 3: 保存完整输出
  const id = Identifier.ascending("tool")  // 生成唯一 ID
  const filepath = path.join(DIR, id)
  await Bun.write(Bun.file(filepath), text)

  // 步骤 4: 生成提示
  const hint = hasTaskTool(agent)
    ? `Full output saved to: ${filepath}\nUse the Task tool to have explore agent process this file.`
    : `Full output saved to: ${filepath}\nUse Grep to search or Read with offset/limit.`

  // 步骤 5: 返回结果
  return {
    content: `${out.join("\n")}\n\n...${removed} ${unit} truncated...\n\n${hint}`,
    truncated: true,
    outputPath: filepath
  }
}
```

## 策略二：会话压缩 (Compaction)

### 触发条件

当每次 LLM 响应完成后，检查是否溢出：

```typescript
// src/session/compaction.ts:30-38
export async function isOverflow(input: {
  tokens: MessageV2.Tokens
  model: Provider.Model
}) {
  const config = await Config.get()
  if (config.compaction?.auto === false) return false  // 可配置关闭

  const context = input.model.limit.context
  if (context === 0) return false

  // 计算 Token 使用量
  const count = input.tokens.input + input.tokens.cache.read + input.tokens.output
  const output = Math.min(input.model.limit.output, SessionPrompt.OUTPUT_TOKEN_MAX)
  const usable = input.model.limit.input || context - output

  // 触发条件：使用量 > 可用量
  return count > usable
}
```

### 源代码详解

```typescript
// src/session/compaction.ts:92-193
export async function process(input: {
  parentID: string
  messages: MessageV2.WithParts[]
  sessionID: string
  abort: AbortSignal
  auto: boolean
}) {
  // 1. 获取用户消息和模型
  const userMessage = input.messages.findLast((m) => m.info.id === input.parentID)!.info
  const agent = await Agent.get("compaction")
  const model = agent.model
    ? await Provider.getModel(agent.model.providerID, agent.model.modelID)
    : await Provider.getModel(userMessage.model.providerID, userMessage.model.modelID)

  // 2. 创建压缩代理消息
  const msg = await Session.updateMessage({
    id: Identifier.ascending("message"),
    role: "assistant",
    parentID: input.parentID,
    sessionID: input.sessionID,
    mode: "compaction",
    agent: "compaction",
    summary: true,  // 标记为摘要
    // ... 其他字段
  })

  // 3. 创建处理器
  const processor = SessionProcessor.create({
    assistantMessage: msg,
    sessionID: input.sessionID,
    model,
    abort: input.abort,
  })

  // 4. 调用 LLM 生成摘要
  const promptText = "Provide a detailed prompt for continuing our conversation above..."
  const result = await processor.process({
    user: userMessage,
    agent,
    abort: input.abort,
    sessionID: input.sessionID,
    tools: {},  // 压缩时不使用工具
    system: [],
    messages: [
      ...MessageV2.toModelMessages(input.messages, model),
      {
        role: "user",
        content: [{ type: "text", text: promptText }],
      },
    ],
    model,
  })

  // 5. 如果是自动压缩，添加继续消息
  if (result === "continue" && input.auto) {
    const continueMsg = await Session.updateMessage({
      id: Identifier.ascending("message"),
      role: "user",
      sessionID: input.sessionID,
      // ...
    })
    await Session.updatePart({
      type: "text",
      synthetic: true,  // 标记为系统生成
      text: "Continue if you have next steps",
    })
  }

  // 6. 发布事件
  Bus.publish(Event.Compacted, { sessionID: input.sessionID })
  return "continue"
}
```

## 策略三：会话剪枝 (Prune)

### 触发条件

剪枝在每次响应完成后**自动执行**，无需等待溢出：

```typescript
// src/session/compaction.ts:49-90
export async function prune(input: { sessionID: string }) {
  const config = await Config.get()
  if (config.compaction?.prune === false) return  // 可配置关闭

  // 获取所有消息
  const msgs = await Session.messages({ sessionID: input.sessionID })

  let total = 0  // 累计 Token
  let pruned = 0  // 已剪枝 Token
  const toPrune = []  // 待剪枝的部分
  let turns = 0  // 对话轮数

  // 从后向前遍历
  for (let msgIndex = msgs.length - 1; msgIndex >= 0; msgIndex--) {
    const msg = msgs[msgIndex]

    // 跳过最近 2 轮对话
    if (msg.info.role === "user") turns++
    if (turns < 2) continue

    // 遇到摘要消息停止
    if (msg.info.role === "assistant" && msg.info.summary) break loop

    // 遍历消息部分
    for (const part of msg.parts) {
      if (part.type === "tool" && part.state.status === "completed") {
        // 跳过保护的工具
        if (PRUNE_PROTECTED_TOOLS.includes(part.tool)) continue

        // 跳过已剪枝的
        if (part.state.time.compacted) break loop

        // 估算 Token 数量
        const estimate = Token.estimate(part.state.output)
        total += estimate

        // 累计超过 40,000 tokens 的工具调用可以剪枝
        if (total > PRUNE_PROTECT) {  // 40,000
          pruned += estimate
          toPrune.push(part)
        }
      }
    }
  }

  // 如果剪枝量超过 20,000 tokens，执行剪枝
  if (pruned > PRUNE_MINIMUM) {  // 20,000
    for (const part of toPrune) {
      part.state.time.compacted = Date.now()
      await Session.updatePart(part)
    }
  }
}
```

### 剪枝与压缩的区别

| 特性 | 剪枝 (Prune) | 压缩 (Compaction) |
|------|-------------|------------------|
| **触发时机** | 每次响应后自动执行 | Token 溢出时触发 |
| **处理方式** | 清除旧工具结果内容 | LLM 生成对话摘要 |
| **保留内容** | 保留工具调用记录，清除输出 | 保留摘要，过滤旧消息 |
| **影响范围** | 只影响工具输出 | 影响整个消息历史 |
| **可逆性** | 内容已丢失 | 摘要保留了关键信息 |

## 策略四：子代理任务分解 (Task)

### 工作原理

Task 工具创建**独立的子会话**，将复杂任务委托给专门的子代理处理：

```typescript
// src/tool/task.ts
execute: async (params, ctx) => {
  // 1. 获取子代理
  const agent = await Agent.get(params.subagent_type)

  // 2. 创建子会话
  const session = await Session.create({
    parentID: ctx.sessionID,  // 父会话 ID
    title: params.description + ` (@${agent.name} subagent)`,
    permission: [/* 限制子代理权限 */],
  })

  // 3. 监听子会话事件
  const unsub = Bus.subscribe(MessageV2.Event.PartUpdated, async (evt) => {
    if (evt.properties.part.sessionID !== session.id) return
    // 更新父会话中的进度
    ctx.metadata({ title: params.description, metadata: { ... } })
  })

  // 4. 发送任务给子代理
  const result = await SessionPrompt.prompt({
    messageID: ctx.messageID,  // 父会话的消息 ID
    sessionID: session.id,      // 子会话 ID
    model: agent.model ?? ctx.model,
    agent: agent.name,
    tools: { /* 禁用某些工具 */ },
    parts: [{ type: "text", text: params.prompt }],
  })

  // 5. 收集结果
  const messages = await Session.messages({ sessionID: session.id })
  const summary = messages
    .filter((x) => x.info.role === "assistant")
    .flatMap((msg) => msg.parts.filter((x) => x.type === "tool"))
    .map((part) => ({
      id: part.id,
      tool: part.tool,
      state: { status: part.state.status, title: part.state.title },
    }))

  const text = result.parts.findLast((x) => x.type === "text")?.text ?? ""

  return {
    title: params.description,
    metadata: { summary, sessionId: session.id },
    output: text + "\n\n" + `<task_metadata>\nsession_id: ${session.id}\n</task_metadata>`,
  }
}
```

### 子会话的优势

1. **独立的 Token 限制**：子会话不会消耗父会话的 Token
2. **隔离的工具执行**：子代理的工具调用不会污染父会话的消息历史
3. **专门的代理**：可以使用最适合任务的代理（如 explore、general）
4. **进度跟踪**：父会话可以通过事件监听子会话的进度
5. **防止递归**：子会话禁用 Task 工具，避免无限递归

## 策略五：批量并行处理 (Batch)

### 工作原理

Batch 工具允许**并行执行多个工具调用**，提高效率：

```typescript
// src/tool/batch.ts
execute: async (params, ctx) => {
  const toolCalls = params.tool_calls.slice(0, 25)  // 最多 25 个
  const discardedCalls = params.tool_calls.slice(25)

  // 并行执行所有工具调用
  const results = await Promise.all(
    toolCalls.map(async (call) => {
      const startTime = Date.now()

      // 创建工具部分
      await Session.updatePart({
        id: partID,
        type: "tool",
        tool: call.tool,
        state: { status: "running", input: call.parameters },
      })

      try {
        const tool = await ToolRegistry.get(call.tool)
        const result = await tool.execute(call.parameters, ctx)

        // 更新为完成状态
        await Session.updatePart({
          state: { status: "completed", output: result.output, ... },
        })

        return { success: true, tool: call.tool, result }
      } catch (error) {
        // 更新为错误状态
        await Session.updatePart({
          state: { status: "error", error: error.message },
        })

        return { success: false, tool: call.tool, error }
      }
    })
  )

  return {
    title: `Batch execution (${successful}/${total} successful)`,
    output: summary,
    metadata: { totalCalls, successful, failed, tools, details },
  }
}
```

## 总结

OpenCode 通过五种策略处理大型代码库：

| 策略 | 触发条件 | 处理方式 | 效果 |
|------|----------|----------|------|
| **Truncate** | 工具输出 > 50KB 或 2000 行 | 保存完整内容到文件，返回截断内容 | 单个工具输出不超限 |
| **Compaction** | Token 使用 > 可用量 | LLM 生成对话摘要 | 释放大量 Token |
| **Prune** | 每次响应后自动执行 | 清除旧工具结果内容 | 持续控制 Token 增长 |
| **Task** | AI 决定分解任务 | 创建子会话委托给子代理 | 任务隔离，独立 Token 限制 |
| **Batch** | AI 决定并行执行 | 并行调用多个工具 | 提高效率，减少等待时间 |

这些策略相互配合，确保 OpenCode 能够高效地处理大型代码库。
