# 斜杠命令与会话管理

## 概述

OpenCode 支持斜杠命令（如 `/new`、`/sessions` 等）来快速执行常见操作。这些命令在 TUI 界面中提供快速访问方式，也可以通过在提示符中直接输入来执行。

| 文件 | 作用 |

| `src/cli/cmd/tui/component/prompt/autocomplete.tsx` | 自动补全、斜杠命令触发 |

### 1. 触发条件


### 2. 命令来源

命令列表来自两个来源：

#### TUI UI 命令（命令对话框）

```typescript
// src/cli/cmd/tui/component/dialog-command.tsx:84-95
slashes() {
  return visibleOptions().flatMap((option) => {
    const slash = option.slash
    if (!slash) return []
    return {
      display: "/" + slash.name,
      description: option.description ?? option.title,
      aliases: slash.aliases?.map((alias) => "/" + alias),
      onSelect: () => result.trigger(option.value),
    }
  })
}
```

#### 服务器端命令

```typescript
// src/cli/cmd/tui/component/prompt/autocomplete.tsx:354-381
const commands = createMemo((): AutocompleteOption[] => {
  const results: AutocompleteOption[] = [...command.slashes()]

  for (const serverCommand of sync.data.command) {
    if (serverCommand.source === "skill") continue
    const label = serverCommand.source === "mcp" ? ":mcp" : ""
    results.push({
      display: "/" + serverCommand.name + label,
      description: serverCommand.description,
      onSelect: () => {
        const newText = "/" + serverCommand.name + " "
        const cursor = props.input().logicalCursor
        props.input().deleteRange(0, 0, cursor.row, cursor.col)
        props.input().insertText(newText)
        props.input().cursorOffset = Bun.stringWidth(newText)
      },
    })
  }

  results.sort((a, b) => a.display.localeCompare(b.display))
  // ...
  return results
})
```

### 3. 命令列表显示

```typescript
// src/cli/cmd/tui/component/prompt/autocomplete.tsx:383-420
const options = createMemo((prev: AutocompleteOption[] | undefined) => {
  const filesValue = files()
  const agentsValue = agents()
  const commandsValue = commands()

  const mixed: AutocompleteOption[] =
    store.visible === "@"
      ? [...agentsValue, ...(filesValue || []), ...mcpResources()]
      : [...commandsValue]

  const searchValue = search()

  if (!searchValue) {
    return mixed
  }

  // 使用 fuzzysort 进行模糊搜索
  const result = fuzzysort.go(removeLineRange(searchValue), mixed, {
    keys: [
      (obj) => removeLineRange((obj.value ?? obj.display).trimEnd()),
      "description",
      (obj) => obj.aliases?.join(" ") ?? "",
    ],
    limit: 10,
    // ...
  })

  return result.map((arr) => arr.obj)
})
```

### 5. 命令数据结构

```typescript
// src/command/index.ts:24-42
```

**命令来源类型：**
- `command`: 内置命令（如 `init`、`review`）
- `mcp`: MCP 协议提供的命令
- `skill`: 技能（通过配置定义的命令）

## `/new` 命令的实现

### 1. 命令注册

```typescript
// src/cli/cmd/tui/app.tsx:302-322
{
  title: "New session",
  suggested: route.data.type === "session",
  value: "session.new",
  keybind: "session_new",
  category: "Session",
  slash: {
    name: "new",
    aliases: ["clear"],
  },
  onSelect: () => {
    const current = promptRef.current
    // 保留当前输入内容
    const currentPrompt = current?.current?.input ? current.current : undefined
    route.navigate({
      type: "home",
      initialPrompt: currentPrompt,
    })
    dialog.clear()
  },
}
```

### 2. `/new` 命令的执行流程

```
用户输入 /new
    ↓
触发 onSelect 回调
    ↓
route.navigate({ type: "home", initialPrompt: currentPrompt })
    ↓
导航到 Home 页面（创建新会话）
    ↓
如果存在 currentPrompt，保留输入内容
```

### 3. 与会话创建的关系

`/new` 命令本身**不直接创建会话**，而是：
1. 导航到 Home 页面
2. 清空当前会话选择
3. 保留用户输入的提示内容

## 其他常见斜杠命令

### TUI UI 命令

| 命令 | 别名 | 功能 |
|------|------|------|
| `/new` | `clear` | 创建新会话 |
| `/sessions` | `resume`, `continue` | 切换会话 |

### 服务器端命令

| 命令 | 描述 | 来源 |
|------|------|------|
| `/init` | create/update AGENTS.md | command |
| `/review` | review changes | command |
| `/<mcp-command>` | MCP 提供的命令 | mcp |
| `/<skill>` | 用户定义的技能 | skill |

## 会话创建的完整流程

```
1. 用户输入 /new
   ↓
2. 导航到 Home 页面 (route.navigate({ type: "home" }))
   ↓
3. 用户输入消息并提交
   ↓
4. 调用 Session.create() 创建新会话
   ↓
5. 调用 SessionPrompt.prompt() 发送消息
   ↓
6. 进入消息处理循环
```

```typescript
export async function createNext(input: {
  id?: string
  title?: string
  parentID?: string
  directory: string
  permission?: PermissionNext.Ruleset
}) {
  const result: Info = {
    id: Identifier.descending("session", input.id),
    slug: Slug.create(),
    version: Installation.VERSION,
    projectID: Instance.project.id,
    directory: input.directory,
    parentID: input.parentID,
    title: input.title ?? createDefaultTitle(!!input.parentID),
    permission: input.permission,
    time: {
      created: Date.now(),
      updated: Date.now(),
    },
  }
  log.info("created", result)
  await Storage.write(["session", Instance.project.id, result.id], result)
  Bus.publish(Event.Created, {
    info: result,
  })
  // ...
  return result
}
```
