# 事件总线

事件总线实现类型安全的发布订阅模式。

## 事件定义

```typescript
export const Event = {
  Created: BusEvent.define(
    "session.created",
    z.object({
      info: Session.Info,
    }),
  ),
  Updated: BusEvent.define(
    "session.updated",
    z.object({
      info: Session.Info,
    }),
  ),
}
```

## 发布事件

```typescript
Bus.publish(Session.Event.Created, {
  info: session,
})
```

## 订阅事件

```typescript
const unsub = Bus.subscribe(Session.Event.Created, (event) => {
  console.log("New session:", event.properties.info)
})

// 取消订阅
unsub()
```

## 订阅所有事件

```typescript
const unsub = Bus.subscribeAll((event) => {
  console.log("Event:", event.type, event.properties)
})
```
