# 配置系统

OpenCode 实现了七层配置优先级系统。

## 配置优先级（从高到低）

1. **Remote `.well-known/opencode`** - 远程配置
2. **全局配置** - `~/.config/opencode/config.json`
3. **自定义配置** - `OPENCODE_CONFIG` 环境变量
4. **项目配置** - `.opencode/config.json`
5. **`.opencode` 目录** - 父目录的配置
6. **内联配置** - 文档内的配置
7. **托管配置** - 企业配置

## 配置结构

```typescript
export const Info = z.object({
  // 模型配置
  model: z.string().optional(),
  default_agent: z.string().optional(),
  agent: z.record(z.string(), AgentConfig).optional(),

  // 权限配置
  permission: z.record(z.string(), z.any()).optional(),

  // 提供商配置
  provider: z.record(z.string(), ProviderConfig).optional(),

  // UI 配置
  ui: z.object({
    theme: z.enum(["light", "dark"]).optional(),
  }).optional(),

  // 实验性功能
  experimental: z.object({
    openTelemetry: z.boolean().optional(),
    continue_loop_on_deny: z.boolean().optional(),
    primary_tools: z.string().array().optional(),
  }).optional(),

  // 其他配置
  username: z.string().optional(),
  share: z.enum(["auto", "disabled", "manual"]).optional(),
  truncate: z.object({
    maxLength: z.number().optional(),
  }).optional(),
})
```

## 配置加载

```typescript
export async function get(): Promise<Info> {
  // 1. 加载全局配置
  const global = await loadGlobal()

  // 2. 加载自定义配置
  const custom = await loadCustom()

  // 3. 加载项目配置
  const project = await loadProject()

  // 4. 加载 .opencode 目录配置
  const opencode = await loadOpencode()

  // 5. 加载远程配置
  const remote = await loadRemote()

  // 6. 合并配置（后面的覆盖前面的）
  return merge(
   托管配置,
    remote,
    global,
    custom,
    project,
    opencode,
    内联配置,
  )
}
```
