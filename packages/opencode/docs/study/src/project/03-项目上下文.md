# 项目上下文与实例管理

项目上下文是 OpenCode 实现"每个目录独立状态"的核心机制。

## 核心概念

### Instance.provide() - 异步上下文管理器

```typescript
await Instance.provide({
  directory: "/path/to/project",
  init: InstanceBootstrap,
  async fn() {
    // 在这个回调内，可以访问：
    // - Instance.project    - 项目信息
    // - Instance.worktree   - 工作树路径
    // - Instance.directory  - 当前目录
    // - Instance.state()    - 实例状态
  }
})
```

### 目录与工作树的区别

```typescript
// directory - 用户指定的目录
Instance.directory = "/path/to/project"

// worktree - Git 工作树根目录
Instance.worktree = "/path/to/project"  // 如果在 Git 仓库中
```

## 实例状态

```typescript
const state = Instance.state(async () => {
  // 惰性初始化的状态
  return {
    // 代理配置
    agents: await loadAgents(),

    // 工具配置
    tools: await loadTools(),

    // ...
  }
})

// 使用
const agents = await state()
```

## HTTP 服务器中的应用

```typescript
// src/server/server.ts
.use(async (c, next) => {
  const raw = c.req.query("directory") || c.req.header("x-opencode-directory") || process.cwd()
  const directory = decodeURIComponent(raw)

  return Instance.provide({
    directory,
    init: InstanceBootstrap,
    async fn() {
      return next()  // 在实例上下文中处理请求
    },
  })
})
```

## 实例销毁

```typescript
// src/project/instance.ts
export async function dispose() {
  // 1. 清理实例状态
  Instance.clear()

  // 2. 发布事件
  Bus.publish(InstanceDisposed, {})

  // 3. 关闭 LSP 连接
  await LSP.disposeAll()

  // 4. 清理 MCP 连接
  await MCP.disposeAll()
}
```
