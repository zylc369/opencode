# OpenCode 学习导航

## 概述

OpenCode 是一个基于 TypeScript 和 Bun 运行时构建的 AI 驱动编程助手，提供多种交互界面（CLI、TUI、Web）来与 AI 模型交互，辅助软件开发任务。

本学习路径按照从整体到局部、从入口到核心、从简单到复杂的原则设计，帮助你系统性地掌握 OpenCode 的架构和实现细节。

## 详细学习步骤

### 第一步：项目整体架构与启动流程
**预计时间：1-2 小时**

**为什么从这一步开始？**
- 建立全局视角，避免迷失在细节中
- 理解核心设计模式，为后续深入理解各模块打下基础
- 了解模块间依赖关系，把握学习重点

**学习内容：**
1. 项目目录结构概览（32个主要子目录）
2. 核心设计模式：
   - 命名空间模式
   - 实例作用域状态
   - 事件驱动架构
   - 插件系统
   - 工具注册表
3. 模块依赖图与数据流向

**相关文档：** `src/01-整体架构.md`

---

### 第二步：入口点与 CLI 层
**预计时间：1-2 小时**

**为什么第二步学这个？**
- `src/index.ts` 是整个应用的启动点
- 理解 CLI 如何使用 Yargs 注册18个命令
- 掌握中间件机制（日志、环境变量设置）和错误处理

**学习内容：**
1. Yargs 命令注册与配置
2. 中间件系统（日志初始化、环境变量）
3. 全局错误处理（未捕获的 Promise 和异常）
4. 命令注册顺序与分类

**相关文档：** `src/cli/02-入口与CLI.md`

---

### 第三步：项目上下文与实例管理
**预计时间：2-3 小时**

**核心概念：**
- `Instance.provide()` - 异步上下文管理器
- 每个目录（项目）独立的实例状态
- 工作树（worktree）与目录（directory）的区别

**为什么很重要？**
这是理解整个项目如何实现"每个项目独立配置和状态"的关键机制。

**相关文档：** `src/project/03-项目上下文.md`

---

### 第四步：配置系统
**预计时间：1-2 小时**

**七层配置优先级（从高到低）：**
1. Remote `.well-known/opencode`
2. 全局配置 (`~/.config/opencode/config.json`)
3. 自定义配置 (`OPENCODE_CONFIG` 环境变量)
4. 项目配置 (`.opencode/config.json`)
5. `.opencode` 目录（父目录）
6. 内联配置（文档内）
7. 托管配置（企业）

**相关文档：** `src/config/04-配置系统.md`

## 学习建议

1. **循序渐进**：按照本导航的顺序学习，不要跳跃
2. **动手实践**：在学习每个模块时，尝试阅读相关源代码
3. **绘制图示**：绘制架构图、流程图帮助理解
4. **关注接口**：重点理解模块间的接口契约，而不仅仅是实现细节
5. **专题深入**：完成基本学习后，选择感兴趣的专题深入研究

## 学习检查点

在每个学习阶段完成后，你应该能够回答以下问题：

- [ ] **第一、二步后**：能否描述 OpenCode 的启动流程和命令注册机制？
- [ ] **第三、四、五步后**：能否解释项目上下文、配置优先级和存储机制？
- [ ] **第六、七、八步后**：能否追踪一个用户请求从输入到 LLM 响应的完整流程？
- [ ] **第九、十、十一步后**：能否描述代理、工具和权限三者如何协同工作？
- [ ] **第十二、十三步后**：能否理解提供商抽象和 HTTP 服务如何支持多种客户端？
- [ ] **第十四步后**：能否独立分析和解释 OpenCode 的核心技术实现？
