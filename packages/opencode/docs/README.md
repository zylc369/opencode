## 🔧 技术栈总览

### 运行时和语言

- **Bun**: 快速 JavaScript 运行时
- **TypeScript**: 类型安全的开发语言
- **ESM**: 现代模块系统

### 核心框架

- **Yargs**: CLI 框架
- **Hono**: Web 框架
- **SolidJS**: UI 框架 (TUI)
- **Vercel AI SDK**: AI 集成

### 工具和库

- **Zod**: 类型验证
- **Bun**: 文件系统和进程管理
- **web-tree-sitter**: 语法解析
- **chokidar**: 文件监控

### 协议支持

- **LSP**: Language Server Protocol
- **MCP**: Model Context Protocol
- **ACP**: Agent Client Protocol

## 🚀 开发指南

### 环境准备

```bash
# 克隆仓库
git clone <repository-url>
cd opencode

# 安装依赖
bun install

# 开发模式
bun run dev

# 类型检查
bun run typecheck

# 运行测试
bun test
```

### 开发流程

1. **功能开发**: 在相应模块中实现功能
2. **测试编写**: 编写单元测试和集成测试
3. **类型检查**: 确保 TypeScript 类型正确
4. **文档更新**: 更新相关文档
5. **提交审核**: 通过代码审核后合并

### 代码规范

- 遵循 TypeScript 最佳实践
- 使用 ESLint 和 Prettier 格式化
- 编写清晰的注释和文档
- 保持测试覆盖率

## 📊 性能优化

## 🔄 版本管理

### 语义化版本

遵循 [Semantic Versioning](https://semver.org/) 规范：

- **主版本**: 不兼容的 API 修改
- **次版本**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 发布流程
