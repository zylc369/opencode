# OpenCode 项目概览

## 项目简介

OpenCode 是一个基于 AI 的代码助手工具，旨在为开发者提供智能化的代码编写、调试和优化体验。该项目使用 TypeScript 开发，基于 Bun 运行时，支持多种 AI 提供商和协议。

## 技术栈

### 核心技术

- **运行时**: Bun (快速 JavaScript 运行时)
- **语言**: TypeScript
- **模块系统**: ESM
- **包管理**: Bun
- **构建工具**: 原生 TypeScript 编译

### 主要依赖

- **AI SDK**: Vercel AI SDK (`ai` 包)
- **Web 框架**: Hono
- **CLI 框架**: Yargs
- **UI 框架**: SolidJS + OpenTUI
- **验证**: Zod
- **语言服务**: vscode-languageserver-types, web-tree-sitter

### AI 提供商支持

- OpenAI (`@ai-sdk/openai`)
- Anthropic (`@ai-sdk/anthropic`)
- Google (`@ai-sdk/google`)
- AWS Bedrock (`@ai-sdk/amazon-bedrock`)
- Azure (`@ai-sdk/azure`)
- Groq (`@ai-sdk/groq`)
- Mistral (`@ai-sdk/mistral`)
- Cohere (`@ai-sdk/cohere`)
- 以及其他多个 AI 提供商

### 协议支持

- **MCP**: Model Context Protocol
- **ACP**: Agent Client Protocol
- **LSP**: Language Server Protocol
- **GitHub**: GitHub Actions 和 API

## 项目架构

OpenCode 采用模块化架构，主要包含以下核心组件：

1. **CLI 工具** - 命令行界面
2. **Tool 系统** - 工具集成框架
3. **Session 管理** - 会话状态管理
4. **Provider 系统** - AI 提供商集成
5. **Plugin 系统** - 插件扩展机制
6. **TUI 界面** - 终端用户界面
7. **LSP 服务器** - 语言服务器集成

## 核心功能

### 命令行功能

- `run` - 运行 AI 助手
- `generate` - 代码生成
- `auth` - 身份认证
- `agent` - 代理管理
- `serve` - 启动服务器
- `web` - Web 界面
- `tui` - 终端界面
- `models` - 模型管理
- `github` - GitHub 集成
- `mcp` - MCP 服务器

### 工具集成

- 文件操作 (read, write, edit)
- 代码搜索 (grep, glob)
- 命令执行 (bash)
- 版本控制 (git)
- 包管理 (npm, bun)
- 语言服务器 (LSP)

### AI 能力

- 代码生成与补全
- 代码审查与优化
- 问题诊断与修复
- 文档生成
- 测试用例生成

## 开发指南

### 安装依赖

```bash
bun install
```

### 开发模式

```bash
bun run dev
```

### 类型检查

```bash
bun run typecheck
```

### 测试

```bash
bun test
```

### 构建

```bash
bun run build
```

## 设计原则

1. **模块化设计** - 每个功能模块独立，便于维护和扩展
2. **协议标准化** - 遵循行业协议如 MCP、LSP 等
3. **提供商无关** - 支持多种 AI 提供商，避免厂商锁定
4. **用户友好** - 提供多种交互方式 (CLI、TUI、Web)
5. **可扩展性** - 通过插件系统支持自定义功能
6. **性能优先** - 使用 Bun 运行时，优化启动和执行速度
