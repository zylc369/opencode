# OpenCode 开发指南

## 概述

本指南为 OpenCode 项目的开发者提供全面的开发指导，包括开发环境搭建、代码规范、最佳实践、测试策略等。基于对源代码的深入分析，本指南旨在帮助新开发者快速上手，并为现有开发者提供参考。

## 项目结构理解

### 快速导航

```bash
# 核心系统
src/session/     # 会话管理 - AI 对话的核心
src/agent/       # AI 代理 - 处理不同类型的 AI 任务
src/tool/        # 工具系统 - 文件操作、命令执行等
src/provider/    # AI 提供商 - OpenAI、Anthropic 等

# 用户界面
src/cli/         # 命令行界面 - 用户交互入口
src/server/      # Web 服务器 - Web 界面后端

# 基础设施
src/project/     # 项目管理 - 工作空间管理
src/config/      # 配置系统 - 配置加载和验证
src/storage/     # 存储抽象 - 数据持久化
src/permission/  # 权限系统 - 安全控制

# 扩展系统
src/plugin/      # 插件系统 - 功能扩展
src/scheduler/   # 调度器 - 任务调度
```

```
用户 → CLI → Bootstrap → Project → Session
                ↓
              Config → Storage
                ↓
Session → Agent → Provider → Tool
                ↓
             Permission → Auth
```

## 核心模块开发指南

### 1. 添加新工具

#### 工具模板

```typescript
// src/tool/my-tool.ts
import { Tool } from "./tool"
import z from "zod"

export const MyTool = Tool.define("my_tool", {
  description: "我的自定义工具",
  parameters: z.object({
    input: z.string().describe("输入参数"),
  }),
  execute: async (args, ctx) => {
    // 检查中断信号
    if (ctx.abort.signal.aborted) {
      throw new Error("Operation aborted")
    }

    // 执行工具逻辑
    const result = await doSomething(args.input)

    return {
      title: "My Tool Result",
      output: result,
      metadata: {},
    }
  },
})
```

#### 注册工具

```typescript
// src/tool/registry.ts
import { MyTool } from "./my-tool"

  return [
    // ... 现有工具
    MyTool,
    // ...
  ]
}
```

### 3. 添加新命令

#### 命令模板

```typescript
// src/cli/cmd/my-command.ts
import { cmd } from "./cmd"
import type { Argv } from "yargs"
import { bootstrap } from "../bootstrap"

export const MyCommand = cmd({
  command: "my-command <arg>",
  describe: "我的自定义命令",
  builder: (yargs: Argv) => {
    return yargs
      .positional("arg", {
        describe: "参数描述",
        type: "string",
      })
      .option("option", {
        alias: "o",
        describe: "选项描述",
        type: "string",
      })
  },
  handler: async (argv) => {
    await bootstrap(process.cwd(), async () => {
      // 命令逻辑
      console.log("执行命令:", argv.arg, argv.option)
    })
  },
})
```

### 2. 运行时性能优化

#### 并行处理

```typescript
// 并行执行独立操作
const [result1, result2, result3] = await Promise.all([operation1(), operation2(), operation3()])
```

#### 缓存策略

```typescript
// 简单缓存实现
const cache = new Map<string, any>()

async function getCachedData(key: string, fetcher: () => Promise<any>) {
  if (cache.has(key)) {
    return cache.get(key)
  }

  const data = await fetcher()
  cache.set(key, data)
  return data
}
```

### 3. 内存管理

#### 及时清理资源

```typescript

  await releaseResource()
}
```

#### 避免内存泄漏


## 常见问题解决

### 1. 类型错误

#### Zod 验证错误

```typescript
// 添加详细的错误格式化
const schema = z.object({
  name: z.string().min(1, "名称不能为空"),
})

// 使用类型安全的方式解析
const result = schema.safeParse(input)
if (!result.success) {
  console.error("验证错误:", result.error.format())
  return
}
```

#### TypeScript 类型推断

```typescript
// 使用类型断言时要小心
const element = document.getElementById("my-id") as HTMLInputElement

// 更好的方式
const element = document.getElementById("my-id")
if (element instanceof HTMLInputElement) {
  // 使用 element
}
```

### 2. 异步操作问题

#### Promise 处理

```typescript
// 避免 async/await 反模式
// 错误示例
const results = []
for (const item of items) {
  const result = await processItem(item)
  results.push(result)
}

// 正确示例 - 并行处理
const results = await Promise.all(items.map((item) => processItem(item)))
```

#### 错误处理

```typescript
// 统一的错误处理
async function safeOperation<T>(operation: () => Promise<T>, fallback: T): Promise<T> {
  try {
    return await operation()
  } catch (error) {
    Log.Default.error("Operation failed", { error })
    return fallback
  }
}
```

### 3. 配置问题

#### 环境变量

```typescript
// 安全的环境变量读取
const config = {
  apiKey: process.env.API_KEY || throw new Error("API_KEY is required"),
  port: parseInt(process.env.PORT || "3000"),
  debug: process.env.NODE_ENV === "development",
}
```

#### 配置验证

```typescript
// 使用 Zod 验证配置
const configSchema = z.object({
  database: z.object({
    url: z.string().url(),
    timeout: z.number().positive().default(5000),
  }),
```

## 社区贡献

### 1. 提交规范

使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```bash
feat: 添加新功能
fix: 修复 bug
docs: 更新文档
style: 代码格式调整
refactor: 代码重构
test: 添加测试
chore: 构建过程或辅助工具的变动
```

### 2. Pull Request 流程

1. **Fork 项目**
2. **创建功能分支**
3. **编写代码和测试**
4. **提交 PR**
5. **代码审核**
6. **合并到主分支**

### 3. 代码审核要点

- 代码风格一致性
- 测试覆盖率
- 性能影响
- 安全考虑
- 文档完整性
